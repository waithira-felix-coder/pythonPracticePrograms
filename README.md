# Python Practice Projects

This repository contains a collection of Python practice programs, scripts, and small projects created for learning and experimentation. New programs are added over time, so this repository is meant to grow as you continue practicing Python.

## Repository Overview

- `abstraction.py` - Example code related to abstraction concepts.
- `class1.py`, `class2.py` - Practice files for working with classes and object-oriented programming.
- `encapsulation.py`, `inheritance.py` - Examples of encapsulation and inheritance.
- `login_app.py` - A small login application project.
- `PredictMl.py` - Machine learning prediction experiment.
- `Snakegame.py` - Python implementation of the classic snake game.
- `snippet.js` - JavaScript snippet included in the practice folder.
- `todo.py` - To-do list application or practice script.
- `weight_convert.py` - A weight conversion utility.
- `tkinter_test.py` - A GUI practice file using Tkinter.
- `test.py` - General test or practice script.

## Subfolders

- `iin/`
  - `in ward patient project/` - Project files for an in-ward patient management or tracking application.

- `MITpythonStudy/`
  - `lec1.py`, `lec2.py` - Lecture practice files from an MIT-style Python study path.

- `Python files/`
  - `clock.bat`, `guess.py`, `guessGame.py`, `polymorphism.py`, `rock_paper_scissorgame.py`, `std.py`, `student mngt.py`, `todoList.py`, and more.
  - This folder contains a broad mix of Python practice programs, learning examples, and small games.

- `pyweek1/`
  - `p2.py`, `p3.py`, `p4Stdreport.py`, `py1.py` - Practice scripts from a Python week 1 challenge or study series.

- `pyweek3/`
  - `patterns1.py`, `patterns2.py` - Pattern-drawing or algorithm practice scripts.

## How to Use

1. Open a script in your Python editor or IDE.
2. Run it using your Python interpreter, for example:
   ```bash
   python Snakegame.py
   ```
3. Add new programs to this repository as you continue learning.
